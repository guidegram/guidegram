## 🌟 Release Highlights

Guidegram v1.7.0 brings a faster, more reliable in-app update experience, introduces a new post-update welcome dialog, refines interface styling to match our refreshed mint-teal brand palette, and improves login session resilience.

---

## 📦 What's New & Enhancements

### 1. ⚡ Seamless In-App Updates & Post-Update Celebration
- **Streamlined Update Delivery**: Optimized background update workflow with automatic verification and smooth restart execution.
- **"What's New" Celebration Modal**: Beautiful native dialog welcoming users after each successful update, highlighting fresh capabilities and release highlights.
- **Reliable State Management**: Enhanced session persistence across application restarts for an uninterrupted experience.

### 2. 🎨 Brand Identity & Theme Refresh
- **Mint-Teal Brand Palette Alignment**: Complete UI color palette harmonization reflecting the official Guidegram logo mint-teal accents.
- **Enhanced Visual Hierarchy**: Refined guest drawer menus, eliminated legacy indicator badges, and elevated high-contrast action buttons for optimal legibility.

### 3. 🔐 Session Connectivity & Channel Sync
- **Enhanced QR Authentication**: Improved QR code login flow with automatic refresh cycles and smoother connection handling.
- **Broadcast Channel Notifications**: Improved notification synchronization ensuring mute and alert preferences are accurately reflected.

### 4. 🌐 Organization Infrastructure Transition
- Fully updated repository endpoints, release assets, and documentation references to the official `guidegram` GitHub organization.

---

## 🐛 Bug Fixes & Stability Improvements
- **Notifications**: Ensured broadcast channel mute states and alert preferences synchronize reliably.
- **Updater**: Improved update state validation and application restart handling.
- **Interface**: Refined guest drawer menu layout and cleaned up legacy indicator badges.
- **Maintenance**: Updated download links and resource endpoints to the official organization repository.
